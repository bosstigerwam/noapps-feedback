# noapps feedback

Bug reports and ideas for **noapps**, the app that brings more than a dozen everyday apps into one, while everything stays on your phone. No account, no cloud, no ads, no tracking.

This repository holds **no source code**. It is only the public place to report what goes wrong and what you would like to see.

## Report a bug

Go to **Issues > New issue > Bug report** and fill in the form:

- app version (for example 1.23.1)
- phone and system (for example iPhone 15, iOS 26.1 or Pixel 8, Android 16)
- the steps that lead to the problem
- what happened and what you expected

Please search the open issues first. If your bug is already there, add a thumbs up or a comment instead of a new issue.

## Suggest an idea

Go to **Issues > New issue > Feature idea**. Tell us what you want to do and why it matters to you.

## Please never post

- backups, keys or the sentence of a guarded layer
- passwords or codes
- personal notes, contacts or anything else private

Cover private content on screenshots before you upload them.

## Security issues

Do not report security problems in public issues. Use **Security > Report a vulnerability** in this repository. Only the noapps team can read those reports.
